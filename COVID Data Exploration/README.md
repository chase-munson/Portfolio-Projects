# COVID-19 Data Exploration & Pipeline
> An end-to-end study of the data analysis pipeline from raw SQL data to an interactive Tableau dashboard.

## Description
Ingested raw COVID-19 data into MS SQL Server, performed transformation queries in SSMS, and audited results in Excel. The final output is an interactive Tableau dashboard showing global infection trends and mortality rates.

## Tech Stack
- **SQL / MS SQL Server / SSMS** — data ingestion and transformation
- **Excel** — data auditing
- **Tableau** — [interactive dashboard](https://public.tableau.com/views/COVIDDataExploration_17660107005600/COVIDDataExploration)
